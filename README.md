# Viranomaisten toiminnan julkisuudesta annetun lain (621/1999) kommentaari

Kommentaari suomalaiseen säädökseen: **Laki viranomaisten toiminnan julkisuudesta 21.5.1999/621** (julkisuuslaki). Kommentaari kattaa **39 pykälää** (1–8 luku, mukaan lukien myöhemmin lisätty 16 a §, kumottu 18 § sekä voimaantulo- ja siirtymäsäännökset) **2 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö, versio **20251079** (ajantasaistettu **28.11.2025**, viimeisin lähteessä mainittu muutos L 28.11.2025/1079, voimaan 1.1.2026).
